## 实验与验证

先读取 pipeline status、三个最优的 generation.json、近期负结果和假设队列。
全部候选显式指定真实输入、配方与比较父候选，没有依赖 `--parent` 继承参数。

1. **符号工作位复用，拒绝。** 新增 `generators/invsqrt_clean_lifetimes.py`，
   对原 62 位 InvSqrt `a568bc793481...` 跟踪 XOR 表达式与规范化非线性节点，
   使用 `x*x=x`、`x*(1+x)=0` 等恒等式；条件写入保守替换为未知量，
   不以某个输入样本或测量分支判定状态为零。只有证明恒零才结束工作位生命周期。
   保留 HMR 和随机记录，允许删除作用于已证零状态的 R。
   候选 `20261031T001842-invsqrt-7abaf2` 用时约 0.39 秒，
   产生 57 次恒零证据、移除 86 个恒等清零操作，但峰值仍为 **40 个工作位 / 总计 62 位**，
   没有减少计分门。不运行无收益的完整验证、不晋升。
   此结果只排除本次表达式规则和不变门序，不排除更强的分支证明、分配律或非线性基重综合。
   9 项测试覆盖条件反算、条件重置、互补乘积、共享操作不重叠、HMR 记录和保守未知量等边界。
2. **InvSqrt，晋升。** 选取 Özer 原始缓存交换条件方案 `6dbb98b34c3b...`，
   由 heliosli notebook v26 / dataset v24 固定版本取得，沿用 yoyobar v4 的 62 位起点。
   缓存较早的交换条件，在后续位置用线性操作恢复，少一次 Toffoli。
   Dmitrii v41 的等资源独立实现只做比较，不按采样微小差异选哈希。
   官方验证覆盖 **200540928 次**，耗时约 **93.04 秒**；最大 Toffoli 从 1502 降到 1501，
   旋转数、精度余量和最差输入 x=161 保持一致。证据 `official-a0dba927.json`。
3. **DFTHC-SOS，晋升。** 比较 5 组权重 × 4 组兼容加载器方案，共 **20 个总成本筛选**。
   包括当前最优、manwithacat、Dmitrii、heliosli、Özer 的权重，以及现有、
   manwithacat、Dmitrii、逐槽最低资源的加载器。所有比较都核对 words/tree 一致，
   并计入完整 PREPARE 开销。三套公开加载器及逐槽选择均为 T=16266、Q=430，
   没有额外计分收益；因此保留当前最优的全部 15 个加载器。
   最优为 Özer notebook v16 / dataset v1 的权重 `47427ee032d3...`，
   来源是 manwithacat 约束重拟合后的进一步优化。
   lambda_eff=48.2956445695，两项残差为 **19.99975405 / 19.99981675 mHa**，
   E_gap=3.91489902899。完整官方验证 **78080 次**，约 **17.75 秒**，
   证据 `official-43526b1d.json`。
4. **DQI，晋升。** 固定 manwithacat notebook v6 / dataset v7 的
   `2ed7ccf189f1...`，实际上游为 SomeJoint、heliosli 与 manwithacat 的拼接和修复路线，
   与比较起点 hengck23 的生成路线区分记录。
   该方案用齐次链重构第 4–7 组，减少偶发零点求逆造成的失败，并使用 888 位。
   在看到验证结果前固定“一次官方 + 两次独立完整复测”的数量，随机种子由既有
   pipeline 在各次运行前生成，不改变哈希、不追加挑选有利结果。
   三次均为 102400 次采样，成本分别 **403339761880.02、403339882538.41、403339994041.70**，
   均优于旧最优；每次约 26–27 秒。本次三次观察到零错误，但不声称覆盖所有低权重输入，
   不改变 DQI 允许非零失败率的官方约定。证据 `official-5c60d9ef.json`、
   `robustness-2f261da4.json`、`robustness-4938e2ea.json` 全部保留。

验证环境为 Conda **vqcc**，解释器 **/root/miniconda3/envs/vqcc/bin/python**，
启动时按 Conda 清单核对 `sys.executable` 与 `sys.prefix`。
官方验证最多 16 个进程，数值筛选的 BLAS/OMP 为单线程；未使用 GPU、子代理或脱管进程。
最终调用 `Pipeline.verified` 核对三个最优的产物、源码快照、运行时和验证器哈希，
复用已经完成的匹配证据，没有再次运行不变的科学验证。
