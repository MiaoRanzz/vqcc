## 数据适配边界

- API 快照附观测时间、源更新时间、revision、freshness、consistency；文件暂不可读时复用上次有效值并标记 stale/partial。
- JSONL 按字节偏移读取完整行，保留近期事件窗口；文件轮换或截断后重建。未记录的历史事件时间不补造。
- 研究备注与排序从 `console/research.json` 读取；原始研究来源不重写。排序和备注改变不改变稳定 ID。
- 报告按注册 ID 访问，只返回脱敏文本。重启后允许的候选元数据、生成/验证报告及运行报告可重建 ID；没有任意目录浏览接口。
- 当前采样字段来自受监督任务。无法取得 GPU 采样时为未知，不显示为 0%；没有可靠阶段分母时不产生进度百分比。
